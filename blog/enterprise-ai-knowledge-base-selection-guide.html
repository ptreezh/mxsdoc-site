与蓝凌 aiKM 的场景对照

蓝凌是数智化办公全平台（OA/BPM/知识管理/低代码），其 aiKM 走"AI 大模型 + 知识图谱 + RAG"路线，与"知识库 + AI"同属一个能力域。两者的关键差异（能力对照）：

  1. 数据主权纯度

    蓝凌云+私有化+信创多形态（有出云形态）；MxsDoc 本地化部署为默认形态，数据不出内网。

  2. 版本控制

    蓝凌以流程/门户为核心；MxsDoc 提供 Git/SVN 级版本树、分支、审计（对接研发协同语义）。

  3. 协同编辑

    蓝凌 OA 文档模块集成化；MxsDoc 类 Word 在线协同 + 可视化权限，零命令门槛。

  4. 成本与落地速度

    蓝凌联合版起步价低但项目制实施重、周期长；MxsDoc 轻量部署、快速上线。

  5. 知识原生理念

    蓝凌"建中台、做图谱、配运营"；MxsDoc"文档进得来 → LLM WIKI 知识留得住 → 专家智能体让 AI 用得上"，小步快跑。

一句话的错位结论：要"数智化办公平台全家桶"选蓝凌；要"数据不出内网、能长出专家智能体的知识库底座"，可以单独评估 MxsDoc——为知识底座付一次钱，而不是为整个平台付一次钱。

三、选型 6 大维度（决策框架）

无论选哪个方案，建议按以下 6 个维度逐项打分，缺一不可：

  1. 数据主权

    涉密、国企、军工场景必须内网；先问"数据能否完全不出内网"，再谈功能。

  2. 版本控制

    制造、设计院类图纸文档，需要 Git 级或同级的版本树、分支、审计；仅"历史版本"不够。

  3. 协同门槛

    全员可用，不学命令行、不学 Markdown；上线即用比功能清单更重要。

  4. 知识治理

    不只是文档存起来，要能沉淀成可检索、可复用的知识资产（LLM WIKI 形态）。

  5. AI 能力

    是"知识库底座 + 专家智能体"的形态，而不是外挂一个 RAG 问答框。

  6. 成本与交付

    轻量部署、快速上线、按规模付费；拒绝"买知识必须先买平台"的隐形成本。

五、10 大选型避坑清单

  • 1.把 RAG 框架当知识库底座——约 30% 的 RAG 项目静默失败，根因是知识源没治理。
  • 2.买了 SaaS 才想起数据主权红线——涉密数据出网一次就是事故，先问部署形态。
  • 3.以为 Git 命令行员工会用——版本能力必须封装成可视化操作，否则等于没买。
  • 4.把蓝凌当知识库买——它是全平台；为知识付全平台的钱，性价比失衡。
  • 5.忽略"知识整理"前置工作——不治理的知识库 = 数字垃圾场。
  • 6.误选"伪本地"——部分产品标称私有化，实际数据仍可出云，逐条核协议。
  • 7.版本控制不是 Git 级——CVS/SVN 老古董或仅有"历史版本"，制造场景会出事故。
  • 8.协同工具 ≠ 文档管理——飞书/腾讯文档协同强，但治理与主权是两回事。
  • 9.忽视审计留痕——涉密场景无审计 = 灭顶之灾，权限与操作记录必须可查。
  • 10.选型不验证真机——没看 demo 就下单，交付不符预期再换成本更高。
